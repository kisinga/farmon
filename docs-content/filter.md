This site has **{{node_kind_count}} filter(s)** — inline filtration on a pipe (sediment, mesh, or media).

- A filter with inlet and outlet pressure sensors exposes a **delta-pressure** reading; a rising delta means the element is clogging and due for service.
- Place a strainer upstream of any flow sensor regardless — debris fouls pulse counters.
- Filters are passive: they don't actuate, they only report. Size the element to the route's flow rate so it doesn't choke the pump.
